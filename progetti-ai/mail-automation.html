Mail
Automation

Un agente che legge le mail non lette, impara il tuo stile dalle inviate e prepara bozze di risposta in Gmail. Non manda niente: le bozze le controlli e le invii tu.

Stato: in uso Tipo: agente locale Accesso: Gmail API Costo: nessuna API key
01

In una frase, e a chi serve

Orientarsi in 30 secondi.

Cos’è. Uno script Python locale che usa Claude Code headless (claude -p) per scrivere le risposte, salvate direttamente in Gmail come bozze.

Il problema che risolve. Rispondere alle mail ripetitive è lento, ma l’invio automatico è rischioso. Qui l’AI prepara e tu invii: la velocità senza il rischio.

Perché è fatto così. Gira in locale sull’abbonamento (zero costo extra, niente API key). OAuth perché lo script lavora fuori dalla chat, ed è idempotente: salva gli id già lavorati.

A chi serve
  • TomasSvuota la posta più in fretta: apre Gmail e trova le bozze già pronte da rivedere.
  • Collaboratore tecnicoInstalla, dà le credenziali Google una volta sola e lancia lo script quando serve.
  • Uso internoStrumento interno: non è esposto a clienti, aiuta solo chi risponde alle mail.

04

Onboarding collaboratore + spiegazione cliente

Allineare chi arriva, e raccontarlo a chi non è tecnico.
Collaboratore - primi passi

Da zero a produttivo

  1. Crea il venv e pip install -r requirements.txt.
  2. Su Google Cloud abilita la Gmail API e scarica credentials.json in secrets/.
  3. Lancia python learn_style.py (login browser una volta).
  4. Lancia python run.py, poi controlla Gmail > Bozze.
Collaboratore - cosa deve saper fare

Le competenze minime

Python di base e terminale, più saper creare credenziali OAuth su Google Cloud. Nient’altro: il testo lo scrive Claude.

Regola d'oro: mai committare secrets/credentials.json o i token. Restano solo in locale.

Come lo spieghi al cliente (non tecnico)

«È un assistente che ti pre-scrive le risposte alle mail nel tuo tono. Tu apri, dai un’occhiata e invii: risparmi tempo senza perdere la tua voce.»

Nessuna mail parte senza che tu l’abbia letta e approvata.

Paletti da spiegare subito
  • Non invia nulla. Prepara soltanto bozze, l’invio è sempre a mano.
  • Segreti in locale. Credenziali e token solo in secrets/, mai nel repo.
  • Salta le automatiche. Newsletter e notifiche vengono ignorate, niente bozze inutili.
